# RIKOMOKO

日本店舗向け 集客・SNSマーケティング支援サイト。日本語を主言語とし、HTML / CSS / JavaScript だけで動作します。RED・多言語発信は必要に応じた追加モジュールです。

## 現在の事業表現

- 支援領域：店舗情報・検索で見つけてもらう／写真・SNSで好きになってもらう／Creator・UGCで信頼を伝える／予約・メニュー等の来店導線を整える。
- 初回商品：店舗集客診断（2〜4ページ・優先提案3点）、SNS Content Test（少量制作・対象媒体を限定）、Creator PR Test（候補と条件を案件ごとに確認）。費用は書面で個別見積もり。
- Aboutに運営者「李」を掲載。所在地・地域拠点・未確認の言語能力・提携先は追加していません。
- DEMO表記、公開前の店舗確認、成果非保証、別途費用とキャンセル条件の事前確認を明示。
- 共有会話URLは取得エラーのため全文未読。現在の会話で伝達された要件に基づき変更しています。

検証：JavaScript構文、リンク・ARIA・素材、3商品と相談選択肢の一致、4場面画像の参照を確認。`node scripts/check-positioning.mjs` で商品表現・相談導線を検査できます。以前のブラウザー接続が安全ポリシーにより拒否されているため、この版のデスクトップ／スマホの実画面検証は未完了です。モバイル向けCSSは実装済みですが、検証済みとは扱いません。

## ローカル確認

`npm run dev` または `node scripts/serve.mjs` で http://127.0.0.1:4173 を開きます。`npm run check` で構文、アンカー、ID、ARIA参照、ローカルアセットを確認します。ビルドや依存パッケージの追加は不要です。

## 現行ファイル

- `red-flow.css` — RED版の連続した背景、曲線の画像処理、サービス一覧の非対称配置、枠線の軽減。red.css の後に読み込みます。今回の静的チェックは通過しましたが、ブラウザー安全ポリシーが既存タブへの接続を拒否したため、この追加調整のスクリーンショット検証は未完了です。

- `index.html` — 店舗集客・SNS支援、3つの初回メニュー、Aboutと相談導線。
- `local-marketing.css` — 4種類の松鼠場面、非対称配置、About、モバイル調整。装飾は画像全体でなく小さな独立アイコンの動作です。停止・減少モーション・画面外停止に対応。
- `red.css` — 基本スタイル。760px / 380px のモバイル対応と reduced-motion に対応。
- `app.js` — メニュー、プラン選択、メール草稿、コピー、プライバシーダイアログ、モバイルCTA。
- `site-config.js` — 既存の問い合わせ先メール設定。公開される情報のため秘密情報を入れないこと。
- `assets/rikomoko-research.png` / `rikomoko-content.png` / `rikomoko-social.png` / `rikomoko-photography.png` — 4種類の生成ブランドイラスト。実在の店舗・実績ではありません。
- `RED-REBUILD.md` — 改修前監査、参考分析、変更内容、必要な実情報。

旧スタイルと旧素材は保持していますが、現行ページは参照しません。画像生成経緯は既存の `assets/README.md` と `assets/scene-prompts.md` を参照してください。

## 問い合わせ
