# RIKOMOKO — current illustration set

Four independent square illustrations: rikomoko-research.png, rikomoko-content.png, rikomoko-social.png, rikomoko-photography.png. All saved in this assets directory. Built-in ImageGen was used; full prompts are in scene-prompts.md.

Shared identity: dazed round golden squirrel, ivory cheeks, enormous fluffy curled tail, navy scarf, acorn brooch. Each has a different setting, pose, props and composition. Illustrations are fictional service explanations, never client cases.

editorial.css animates separate inline SVG accents over the illustrations. The bitmap and mascot do not move as a whole. Historic SVG / PNG character variants remain on disk but are not referenced by the live page.
